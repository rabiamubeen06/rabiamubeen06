## Projects

### [ChatShat](https://github.com/rabiamubeen06/ChatShat)
Real-time chat app with Socket.IO messaging and Supabase authentication, including guest login and Arcjet-based rate limiting.
`React` `Socket.IO` `Express` `MongoDB` `Supabase`
[Live demo](https://chatshat.up.railway.app/)

### [NovelsNest](https://github.com/rabiamubeen06/Novels-Nest)
Novel discovery and review platform with Google OAuth and a stateless, JWT-verified API.
`React` `Redux Toolkit` `Express` `MongoDB` `Jose`
[Live demo](https://novels-nest.vercel.app/)

### [HashGlitch](https://github.com/rabiamubeen06/HashGlitch)
Desktop app that fingerprints files with SHA-256 and alerts instantly on unauthorized changes.
`Electron` `Express` `WebSockets` `Chokidar`

### [Network Traffic Monitor](https://github.com/rabiamubeen06/network_traffic_monitor)
Simulated university LAN traffic monitor with a rule-based engine for detecting DDoS patterns and suspicious activity.
`Python` `Flask` `JavaScript`
*(local-only, run via `python main.py`)*
